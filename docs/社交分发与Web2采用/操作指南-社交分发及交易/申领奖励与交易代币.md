# 申领奖励与交易代币

1.申领社交分发奖励 -- 流程：点击「头像」→ 进入「Tweet/Space」页面→ 点击「Claimable」并点「Claim」→ 签名确认后奖励到账。

2.交易社区代币（以$BUIDL为例） -- 流程：点击首页「Tag」→ 进入「Tag Coin」板块选择「BUIDL」→ 点击「Trade」→ 输入BNB数量后点「Confirm」→ 授权交易并点「All Done」。
