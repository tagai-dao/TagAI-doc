# 创作与质押式策展

方式1：TagAI 上发布帖子至链上社区\
\--流程：点击首页右下角「+」→ 编辑内容并选择社区→ 点「发布推文」发布。\
\--作用：将帖子发布到脸上社区，创作者和质押式策展的参与者均可获得代币奖励。

方式2：在 X（Twitter）发布新帖至链上社区\
\--流程：发布X帖子时附带 “#TagAI #ticker”（如 “#TagAI #BUIDL”或“#TagAI #币安小说”）；带#ticker就是进入哪一个社区，#BUIDL就是进BUIDL社区，#币安小说”就是进入币安小说社区。

方式3：将 X（Twitter）已有帖子引入链上社区\
\-- 流程：打开X帖子评论区→ 留言并附带 “@TagAIDAO tip $ticker”（如 “@TagAIDAO tip $BUIDL”或“@TagAIDAO tip $币安小说”）。
