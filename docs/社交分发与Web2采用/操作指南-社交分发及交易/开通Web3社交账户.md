# 开通 Web3 社交账户

\--流程：回到 TagAI 首页后，先点任意帖子下的🔥，触发开通确认弹窗就点 “立即开通”；接着在交易确认弹窗核对信息后点 “确认”；交易完成后在 “Transaction completed” 界面点 “All Done 完成开通”；最后在 “Sign message 签名消息” 弹窗点 “Sign and continue 签名继续”。

\--作用：正式生成了你的 Web3 社交账号，开启在 TagAI 的社交互动与收益之旅啦\~
