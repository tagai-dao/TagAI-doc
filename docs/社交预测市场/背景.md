# 背景

最近，vitalik 在“the target is not Europe, it’s the EU”的讨论中<sup>\[01]</sup>，表达了其对社交媒体推荐算法的担忧，并呼吁我们需要有一个透明、可验证的算法和数据<sup>\[02]</sup>*。*&#x76;italik 还提议开发者可以围绕 X 等社媒开发替代客户端<sup>\[03]</sup> —— 来过滤掉机器人等，优化 X 平台的信息发现，更好地分配人们的注意力。

Vitalik 揭示了当下的一个迫切需求：随着科技和社交媒体平台的发展，人类的绝大多数注意力几乎完全由巨型公司进行分配，我们需要**打上时间戳的社交数据**、**可验证的算法**、**“真相友好”的公共讨论**、**去中心化的客户端**和**多元信息发现机制**。即我们需要新的分发机制 —— 分配全球注意力。

这一迫切需求随着 AI 和区块链的飞速发展，更加紧急。内容创作和产品开发已经变得更容易，而之后的分发成为了核心。

#### **信息/事件 × 开放金融**

Nick Shirley 在 X、Instagram、YouTube 等社交媒体上发布了多则自己的走访调查视频<sup>\[04]</sup>后，人们在 Pump.Fun、Zora 为该事件或 Nick Shirley 发行了代币，并在 Polymarket 为事件创建了预测市场，Nick Shirley 还将他的 Venmo 和加密货币地址分享了出来<sup>\[05]</sup>。这些事件让我们见识到了一场网络媒介与开放金融的合舞表演。

这些事件让我们看到：去中心化协议正在以**更低摩擦、更透明的方式**分发信息以及完成注意力货币化的闭环，不管是在政治、体育事件的预测，还是网络媒体的传播与扩散。

这是一种继编辑分发、订阅分发、搜索引擎分发、社交分发和算法推荐分发之后的一种新的信息分发方式。随着区块链、AI 和用户需求的变化，信息分发也正向更智能、多样化和用户主导的方向演进。

#### **社交预测市场**

Polymarket 通过金钱激励的集体预测集合了人群智慧，将意见转化为可量化的概率。这使得它靠真实资金押注制造“真相信号” —— 正在从政治、体育、金融期货等事件中，走向新的社交媒体网络真相来源 —— **信息发现层**。

Manifold 在继承了 Polymarket 的预测机制之后，添加了强烈的社交互动和社区驱动元素，使其更像一个”预测版 reddit“。高度社区化、任何人可快速上线小众、趣味或长期话题，这些带来了上万个多样化市场（像 Reddit 的无数 subreddit）。Manifold 成为了带有预测机制的社区论坛。

X 等社交媒体平台作为“数字城邦广场”和追求最大化真相的平台，已经成为互联网上最佳真相来源。与此同时，现实世界中的任何“话题性”事件都在 X 等社交媒体平台广泛讨论。

我们是否可以将 X 等社交媒体平台与预测市场、社区代币/社交代币进行组合，以现实世界事件或者 X 等社媒上的话题为起点，创建链上社区、部署代币、开通各种预测市场以及使用社区代币进行押注预测？

这就是社交预测市场 —— 一个将 web2 社交媒体网络与预测市场、社区代币、社交代币结合的自由、多边市场。如此，我们可以：

* 以链上社区的点赞/转发和预测市场的概率，决定 X 等社媒平台帖子的分发；
* 根据人们参与预测市场的分数，赋予更高的信用、推送权重和创作者分成；
* 结合 AI + 预测市场，为社交媒体网络构建“真相引擎”；
* 无缝支持加密货币支付和 mini apps 的开发，并形成超级流动性池；
* 让数十亿社媒用户即刻拥有钱包，并在社交预测/ 分发等场景实现加密货币支付和交易的采用。
