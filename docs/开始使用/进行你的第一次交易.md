# 进行你的第一次交易

#### **交易准备：**

1\) 连接钱包到Tagai平台

2\) 确保钱包中有社区代币（比如 $币安小说 或 $BUIDL）和少量BNB（用于手续费）

**买卖操作：**

1）浏览市场：在社区预测界面找到感兴趣的预测

2）点击交易：选择要参与的市场，点击“交易”按钮

![](https://3381154666-files.gitbook.io/~/files/v0/b/gitbook-x-prod.appspot.com/o/spaces%2F5W3YHzppdMaC2HCthnq8%2Fuploads%2FrcnT4vozkfpPk00d7TRH%2Funknown.png?alt=media\&token=04345f28-9314-4467-ba82-43e6af52b553)

选择方向：

* 买入红方：看好红方帖子会赢
* 买入蓝方：看好蓝方帖子会赢
* 卖出持仓：获利了结或止损

输入数量：

* 买入时：输入花费的BUIDL数量
* 卖出时：输入持有的结果代币数量

#### **交易费用：**

社区代币手续费（BUIDL结算）：

* 费率：1%-10%
* 规则：越接近结果公布时间，费率越高
* 去向：全部分配给做市商

平台手续费（BNB结算）：

* 费率：0.3%
* 计算：按交易的社区代币当前价值计算
* 去向：Tagai平台方
