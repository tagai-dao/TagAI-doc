# 如何存款？

\--流程：进入钱包界面，可查看BNB余额、交易记录；点击“存入BNB”，复制钱包地址，从外部钱包转账至少0.001 BNB到该地址完成充值。

\--作用：管理你的数字资产，为参与平台活动准备资金。
