# 创建社交预测

第1步：

选择对战帖子

* 输入预测标题
* 分别粘贴“红方”和“蓝方”的推特链接

设置初始概率

* 根据您的判断设定双方胜率
* 例如：认为红方70%胜率，蓝方30%胜率（这将决定市场的起始价格）

注入启动资金

* 使用BUIDL代币作为做市资金
* 建议金额：10万-100万BUIDL
* 资金量影响：
  资金越多 → 价格波动越平缓
* 资金越少 → 价格波动越剧烈

第2步：确认创建

需要签署两次交易：

* 授权BUIDL代币使用
* 创建预测市场

创建成功后获得：

* LP代币（流动性凭证）
* 根据初始概率获得对应的结果代币

⚠️关于帖子要求：

如果帖子不在Tagai平台：消耗400 OP引入社区

如果帖子已在Tagai平台：

* 不能属于其他社区
* 如果在BUIDL社区，必须是当天发布的
* 只有一个帖子在Tagai：消耗200 OP
* 两个帖子都在Tagai：不消耗OP
