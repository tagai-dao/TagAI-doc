# 预测什么？

只要是 X、Reddit 等社交媒体网络上任何帖子所代表的事件、话题等，都可以使用 TagAI 创建预测市场。不管其代表的是政治、体育、文化等现实世界正在发生的事件，还是 X、Reddit 上社区事件、人们对某些观点的讨论。

#### 预测事件的类型

**社交类预测**

可以把 TagAI 看成是基于 X 等社交媒体平台的信息，构建一个”预测市场（像 Polymarket）+社区讨论论坛（像 Reddit）“的结合体。其基础目标则是，利用预测市场，把 X 上的每一条信息都打上”市场共识价格“。

与 Polymarket 预测政治、体育等事件不同，TagAI 上独特的预测是与社区有关的话题、事件或内容。主要有以下几类（以 X 上信息为例）：

* **A. 链上互动数据**：帖子/Space 在链上社区的互动（点赞、转发等）数据，需符合社区信用条件才能纳入计算；
* **B. 信息流行度**：帖子/Space 在链上社区的流行度排名，以及两篇或多篇帖子在链上社区的流行度排名；
* **C. 帖子 pk**：两篇帖子/Space 的社区互动 pk，决定社区的发展（比如生成式游戏的未来场景、文化作品的剧情发展）；
* **D. 社区治理投票帖的 Y/N 押注**：对社区治理投票帖子进行二元押注；
* **E. 社区笔记帖是否会删除**：对 X 附带社区笔记的帖子，押注创作者是否会 or 何时删帖；
* **F. 账号的链上排名**：X 上账号的链上社区排名；

**政治、体育等事件的预测**

对于 Polymarket、Kalshi 等预测市场的事件，只要这些事件被人们在 X、Reddit 上讨论，任何人都可以围绕这些事件创建预测市场。

一旦这些政治、体育、文化等预测事件被创建，人们可以在 X、Reddit 的页面原生参与，亦可在参与过程中获得代币的奖励。

#### 两个场景

预测市场让人们看到，Polymarket、Kalshi 等可以用经济激励聚合真实信息，优于民调等投票机制。

虽然部分人认为：预测市场本身并不总是理想的信息聚合工具，对于”微观“的问题，参与预测的资金池往往过小，难以形成有意义的信号。

但，我们认为预测市场更重要的是巧妙地利用区块链的开放、可升级的激励体系以及实时输出结果的特性，为我们创建了一个取代中心化决策的市场。它将推动一个市场取代中心化决策，超级节点与节点主导的动态社会 —— 亦将应用在众多场景中。

比如：在 DAO 投票场景中，投票率不足大大限制了 DAO 治理的效率以及真实性。LayerZero 最近的公投 #3<sup>*\[06]*</sup>，门槛计划达到 9350 万票，实际投票仅 340 万票。

围绕 DAO 提案通过与否的预测市场带来的未来激励，会促使参与者参与 DAO 提案投票，这将大大解决以往 DAO 治理投票对于大多数人来说的高心理参与门槛/成本。

同样，在社交媒体网络中注意力金融化的过程中，大部分用户作为阅读者已经获得极大价值。由于创作和策展的高成本，使得大部分用户难以投入精力在社区事件、话题或内容的讨论与策展（治理中），这反而让女巫攻击和撸毛工作室有机可乘。固，我们看到过去几年：任务平台鼎盛、AI 创作 & 策展迅猛发展、一场 Twitter Space 98% 参与者为机器、无法分别大部分帖子的真实与虚假点赞。

融入质押媒体的社交预测市场，一方面提高了 AI、机器投票 & 造假的成本；另一方面，则让预测市场的参与者会积极参与帖子的链上互动、积极表达自己的观点，以佐证自己的押注预测。并且，社交预测市场还让人们可以围绕社交媒体网络中的信息进行游戏化玩法的设计。对此，我们可以查看最近展开的 IP 故事预测<sup>*\[07]*</sup>。
